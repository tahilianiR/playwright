# JavaScript Basics

| Category | Expression | Details | Example |
|----------|------------|---------|---------|
| Math | `Math.abs()` | Returns the absolute value of a number, which is the number without its minus sign | `Math.abs(-5)` → `5` |
| Math | `Math.round()` | Rounds a number to the nearest integer | `Math.round(4.6)` → `5` |
| Math | `Math.floor()` | Rounds a number down to the nearest integer | `Math.floor(4.9)` → `4` |
| Math | `Math.ceil()` | Rounds a number up to the nearest integer | `Math.ceil(4.1)` → `5` |
| Math | `Math.max()` | Returns the largest of the given numbers | `Math.max(1, 7, 3)` → `7` |
| Math | `Math.min()` | Returns the smallest of the given numbers | `Math.min(1, 7, 3)` → `1` |
| Math | `Math.pow()` | Returns the base raised to the exponent power | `Math.pow(2, 3)` → `8` |
| Math | `Math.sqrt()` | Returns the square root of a number | `Math.sqrt(16)` → `4` |
| Math | `Math.random()` | Returns a random number from 0 (inclusive) up to 1 (exclusive) | `Math.floor(Math.random() * 10)` → `0` to `9` |
