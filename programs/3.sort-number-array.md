### approach 1 - sort function

To sort a number array in TypeScript, always pass a compare function:

```ts
const nums = [10, 2, 33, 1, 5];
nums.sort((a, b) => a - b);   // ascending:  [1, 2, 5, 10, 33]
nums.sort((a, b) => b - a);   // descending: [33, 10, 5, 2, 1]
```

Why you need (a, b) => a - b: without it, sort() compares the numbers as text:

typescript
[10, 2, 33, 1, 5].sort();   // [1, 10, 2, 33, 5]  ← wrong: '10' comes before '2' as text

How the compare function works: sort calls it with two items and uses the sign of the result.

Negative (for example 2 - 10 = -8): a goes before b.
Positive: b goes before a.
Zero: their order stays the same.

So a - b puts smaller numbers first, and b - a puts bigger numbers first


### approach 2 - double for loop
```ts
const arr = [2,1,3,4]

const sortedArr = [...arr]  //That line makes a copy of the array arr using the spread operator ....

for(let i=0;i<arr.length;i++) {
  
  for(let j=i+1;j<=sortedArr.length;j++) {
    if(sortedArr[j] < sortedArr[i] ) {
      const temp = sortedArr[j]
      sortedArr[j] = sortedArr[i]
      sortedArr[i] = temp      
    }
  }

}

console.log(sortedArr)
```
