 `n!` is the product of all whole numbers from 1 to n. `0!` is 1.

`5!` = 5 x 4 x 3 x 2 x 1 = `120`

### Approach 1: loop

```ts
function factorial(n: number): number {

  if (n < 0) throw new Error('Factorial is not defined for negative numbers');
  
  let result = 1;
  for (let i = 2; i <= n; i++) {
    result *= i;
  }
  return result;

}

console.log(factorial(5)); // 120
console.log(factorial(1)); // 1
console.log(factorial(0)); // 1
```

### Approach 2: recursion

```ts
function factorial(n: number): number {
  if (n < 0) throw new Error('Factorial is not defined for negative numbers');
  if (n <= 1) return 1; // base case
  return n * factorial(n - 1);
}
```

### Notes
- `0!` and `1!` are both 1. This is the base case that stops the recursion.
- Time complexity is O(n). Recursion also uses O(n) stack space, so the loop is safer for large n.
- `number` loses precision above `18!`. Use `BigInt` for big values.
